# Connect6

Privacy-first decentralized peer-to-peer communication platform built in Go.

## Features
- IPv6 peer-to-peer communication
- Modular node architecture
- Concurrent peer handling
- JSON protocol messaging
- Dockerized distributed testing
- Manual trust-based peer connectivity

## Run

go run ./cmd/node

## Docker

docker build -t connect6 .
